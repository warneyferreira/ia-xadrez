# Configurações de confrontos

Copie `arena/example-config.json` para esta pasta e dê ao arquivo um nome que
revele os dois commits, por exemplo `2026-10-30-arthur-a1b2-vanderlei-c3d4.json`.

Cada arquivo deve apontar para binários distintos e registrar a mesma
configuração UCI para ambos. Não reutilize um `output_dir` de match anterior:
a arena se recusa a sobrescrever evidências.
